Your work. Your files.

Open Draft prepares contributions for English Wikibooks and Wikimedia Commons. It is independent of Wikimedia and does not publish on your behalf.

A first project in six steps

  1. Set a purpose. Enter the book title, contributor credit, audience, scope, and destination. Choose a license only for rights you control.
  2. Write and organize. Create pages, add section headings and paragraphs, and use the move buttons to arrange them. Use plain text; the app generates markup.
  3. Record sources and media. Add references and attach them to blocks. Add images, their alternatives and captions, authorship, original sources, license, and permission evidence.
  4. Review. Resolve checks and inspect the reading preview. Review rights, factual claims, neutral presentation, and accessibility yourself.
  5. Download. Save a project JSON file to reopen later. The contribution ZIP includes publication instructions, attribution, media, and (for Wikibooks) separate page files. HTML is a reading and print draft.
  6. Preview on the wiki. Follow START-HERE.md. Upload eligible media through Commons Upload Wizard and prepare each Wikibooks page separately. Sandbox edits are public. Check existing pages before making changes.

Use the wiki translator

Choose Wiki translator in the sidebar. Type and format text on the left; copy or download the wiki code on the right. Select words before using Bold, Italic, or adding a link. Plain-text paste removes hidden formatting. Optional colors are included only when the chosen pair meets 4.5:1. UDL cards offer editable starters and explain their purpose. Preview the result in the destination wiki.

The scratchpad stays separate from book chapters and is included in project backups and as translator-draft.wiki in contribution ZIPs. It does not appear in the book reading HTML. Complete any starter prompts, add needed sources, and review rights before publishing.

What “temporary save” means

By default the app keeps a working copy in this tab’s session storage. It can survive a refresh. Closing the tab usually ends the session, but browser recovery or duplicated tabs may retain copies. This is not a backup or a secure-erasure guarantee. Download your project regularly, particularly before closing the browser.

Use Clear temporary copy to remove this app’s stored working copy and switch to memory-only mode. The current project stays on screen. New blank project replaces it. Private browsing, storage settings, and quota limits can prevent saving; a visible message tells you when that happens.

Where files go

Selected files are read locally. This app has no upload endpoint, accounts, analytics, remote fonts, or AI service. It does not send project content to a server. The hosting provider still receives normal requests for the app itself. Selecting an external guidance link visits that other website. Downloads go to your browser’s configured download location.

All paths on a GitHub Pages domain share an origin. Avoid hosting untrusted scripts alongside this app on the same domain; use a dedicated domain when appropriate. Temporary storage is not encrypted by this app. Never treat it as a confidential records system.

Rights and open education

Openly licensed materials can support sharing, translation, adaptation, and ongoing improvement. Free access alone does not make a resource OER. The app supports private drafts and reserved rights too. Each media item retains its own license; project licensing never overrides it.

Copyright attribution and academic citation serve different purposes. Record both. The prototype handles a small set of common CC options; more complex public-domain, permission, historical-license, and mixed-rights cases need individual review. Commons requires eligible freely reusable media; its licensing and scope rules still apply.

Accessibility and scope

The interface uses labeled native controls, keyboard reorder controls, visible focus, status messages, and semantic structure. These are design measures, not a certification. Automated checks cannot judge meaningful image descriptions, correct facts, lawful reuse, or the full screen-reader experience. Review exported content in the actual wiki and reading system.

This version supports English text, headings, paragraphs, lists, quotations, image blocks, and references. Images are treated as informative; supply a contextual alternative. For complex images, add an explanatory paragraph. Tables, mathematical notation, audio/video, multilingual metadata, IMSCC conversion, EPUB, verified tagged PDF, and account-based publication are future work. Browser “Save as PDF” is not verified PDF/UA.

Limits: 50 pages, 200 blocks per page, 100 references, 20 raster images, 1.5 MB per imported image, and a 4 MB project. JSON is the editable file format. ZIP is a contribution handoff, not a universal Wikimedia importer.
