## 0.1.0 — 2026-10-16

First numbered working prototype. The earlier unnumbered draft is incorporated into this release.

- Local-first Wikibooks and Wikimedia Commons authoring and contribution exports.
- Structured pages, citations, media rights, alternative text, and review prompts.
- Temporary browser working copy and portable project JSON downloads.
- Reading HTML, wiki source, contribution ZIP, and GitHub Pages instructions.
- Visible version/date, AI-assisted development disclosure, technology and testing explanation, and CC BY-NC-SA 4.0 notice for original app code and documentation.

Project-file schema remains version 1. Application release versions and project-file schema versions are separate; adding release labels does not invalidate existing project files.
